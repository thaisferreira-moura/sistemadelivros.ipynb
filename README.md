## 💻 Sobre o projeto

O **Sistema de Livros em Python** é um projeto desenvolvido durante meus estudos em programação, com o objetivo de praticar conceitos fundamentais da linguagem Python e lógica de programação.

O sistema permite realizar o gerenciamento de livros através de um menu interativo, possibilitando o cadastro, visualização, busca, atualização e remoção de livros.

Este projeto foi desenvolvido com foco na prática de **estruturas condicionais, estruturas de repetição, funções, listas, dicionários e entrada de dados pelo usuário**, consolidando conhecimentos essenciais para o desenvolvimento em Python.
